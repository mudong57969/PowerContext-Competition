# 数据结构与算法

> 本讲义为 UAT2 验收测试材料（由 Qoder 撰写），内容为标准数据结构课程知识，
> 用于测试「词典中不存在的新课程」识别。

## 第一章 线性表

线性表是 n 个数据元素的有限序列。顺序表用连续内存存储，支持随机访问，
插入删除需移动元素。链表通过指针链接节点，插入删除只需修改指针，
但查找必须从头遍历。栈 stack 是后进先出（LIFO）的线性表，
队列 queue 是先进先出（FIFO）的线性表。

## 第二章 树与二叉树

树 tree 是 n 个节点的有限集合，根节点没有前驱。二叉树每个节点至多两个子树。
满二叉树、完全二叉树是常见的特殊形态。二叉树的遍历方式有先序、中序、后序
与层次遍历。二叉排序树（BST）满足左子树小于根、右子树大于根的性质，
平衡二叉树的查找、插入、删除时间复杂度均为 O(log n)。

## 第三章 图

图 graph 由顶点集合和边集合组成，分为有向图与无向图。图的存储方式有
邻接矩阵与邻接表。深度优先搜索（DFS）使用栈或递归实现，广度优先搜索（BFS）
使用队列实现。最短路径问题可用 Dijkstra 算法求解，最小生成树可用
Prim 算法或 Kruskal 算法构造。

## 第四章 查找与排序

顺序查找的时间复杂度为 O(n)，二分查找要求有序表且为 O(log n)。
哈希表 hash table 通过哈希函数将关键字映射到地址，冲突处理方法有
开放定址法与链地址法。排序算法：冒泡排序、插入排序、快速排序、
归并排序、堆排序。快速排序平均时间复杂度为 O(n log n)，
冒泡排序为 O(n²)，归并排序是稳定的排序算法。
